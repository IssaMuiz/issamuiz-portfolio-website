# AI Automation Studio

Build a modern, professional personal portfolio website for **Issa Muiz**, an **AI Automation Engineer**.

The website is intended to attract potential business clients who need AI-powered automation and business systems.

### Core positioning

The primary message should communicate:

**AI Automation Engineer building AI-powered business systems that automate repetitive work, improve customer operations, and help businesses work more efficiently.**

Do not position the site as a generic software developer portfolio. The focus should be on solving business problems through AI, automation, integrations, and practical software systems.

### Visual direction

Use a **dark premium theme**.

* Deep navy / near-black background
* Electric blue as the primary accent
* Subtle cyan accents where appropriate
* White/off-white primary text
* Muted blue-grey secondary text
* Dark elevated cards
* Subtle borders
* Modern sans-serif typography
* Generous whitespace
* Strong visual hierarchy
* Subtle hover and entrance animations
* Smooth scrolling
* Fully responsive across desktop, tablet and mobile

Avoid excessive gradients, glowing effects, particles, futuristic animations, stock illustrations, or anything that makes the website look like a gaming or crypto website.

The overall impression should be **professional, credible, modern and technically capable**.

### Page structure

Create a single-page portfolio with these sections:

1. Hero
2. Problems I Solve
3. Services
4. Selected Work
5. How I Work
6. About
7. Technology
8. Contact
9. Footer

### Hero

Display:

**Issa Muiz**

**AI Automation Engineer**

Main message:

**Building AI-powered systems that automate repetitive work and improve business operations.**

Include two clear buttons:

**Work With Me**
**View My Work**

The hero should immediately communicate what I do and the type of business problems I solve.

### Problems I Solve

Create four concise problem cards:

* Customer Support Overload
* Poor Lead Follow-up
* Manual Document Processing
* Repetitive Business Operations

Explain each problem briefly from the perspective of a business owner.

### Services

Create four service cards:

1. **AI Customer Support**
   Automate repetitive customer enquiries using business knowledge, while routing cases requiring human intervention.

2. **AI Lead & Sales Automation**
   Capture, qualify, route and follow up with leads through automated workflows.

3. **AI Document Processing**
   Extract, structure and process useful information from business documents.

4. **Business Process Automation**
   Transform repetitive manual business processes into connected automated systems.

### Selected Work

Create a clean project showcase with these projects:

**AI Customer Support System**
Status: In Development

**Poultry Flock Health Triage System**
A computer vision application for classifying poultry health conditions from images.

**Sentiment Analysis API**
An NLP system for classifying text sentiment through an API.

**Inventory Intelligence**
A data-driven project focused on extracting useful insights from inventory and retail data.

Use project cards with space for a future demo link, GitHub link and case study.

Do not invent project results, client names or testimonials.

### How I Work

Show a simple six-step process:

1. Understand the business process
2. Identify automation opportunities
3. Design the solution
4. Build and integrate
5. Test and validate
6. Deploy and improve

### About

Introduce Issa Muiz as an AI Automation Engineer with a background in building machine learning and AI applications, now focused on applying AI and automation to practical business problems.

Keep this section concise and credible. Do not claim years of professional AI experience or client experience that has not been established.

### Technology

Present the technologies as supporting tools rather than the main selling point.

Include:

n8n, Supabase, Lovable, Python, JavaScript, REST APIs, Webhooks, SQL, AI APIs, FastAPI, Streamlit, Docker, Git and GitHub.

### Contact

Create a clear final call-to-action:

**Have a repetitive business process that could be automated?**

Invite visitors to get in touch.

Display:

Email: [issamuiz@gmail.com](mailto:issamuiz@gmail.com)

LinkedIn: Issa Muiz

GitHub: IssaMuiz

For now, the contact section does not need a backend or database. Use simple links/buttons.

### Technical requirements

* Frontend only for this version
* No authentication
* No database
* No Supabase integration yet
* No n8n integration yet
* No backend
* Responsive design
* Accessible semantic HTML
* Reusable components
* Clean component structure
* Maintainable code
* Good mobile navigation
* Optimized page performance
* SEO-friendly page title and metadata
